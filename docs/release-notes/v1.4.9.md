# v1.4.9 返回时回到原处

发布日期：2026-10-29

基于版本：v1.4.8

---

## 一、这一版带来了什么

| | 以前的样子 | 现在的样子 |
| --- | --- | --- |
| 从子目录返回上一层（返回键 / 左上角箭头 / 「上一层」） | 列表跳回**最顶上**，想接着看刚才那一段得重新往下翻 | 停在刚才离开时的那一行，连那一行被推上去多少像素都一样 |
| 再进一个**看过的**目录 | 一样从最顶上开始 | 回到上次离开时的位置 |
| 点顶端的路径条跳回更上面某一层 | 一样从最顶上开始 | 那一层保持它上次的位置 |
| 顶端的目录路径（面包屑） | 路径一长就只剩开头「内部存储 › Download › …」，**当前在哪一层**被挤到屏幕右边看不见 | 自动停到最右端，看见的永远是「从当前这一层往上数」的那一段 |

一句话：**返回上一层，列表还在你刚才站的地方；顶端的路径也不再只露开头。**

## 二、怎么用

### 1. 记住滚动位置

1. 打开「浏览」，进一个文件多的目录（比如 `Download`），往下翻到中间。
2. 进其中一个子文件夹，再按返回键（或者点左上角的返回箭头）回到上一层 ——
   列表停在刚才翻到的地方，不是最顶上。
3. 再进那个子文件夹、再退出来，来回几次都一样。
4. 点顶端的路径条跳回更上面的某一层，那一层也是它上次离开时的位置。

括号里那个位置是**像素级**的：记的是「第几条停在第一行」+「这一条被推上去多少像素」。
所以屏幕上的画面和离开时一致，不是「大概翻到那一带」。

### 2. 顶端的路径自动停在当前目录那一端

进到深一点的目录，比如 `内部存储 › Movies › 某部电影 › Season 1`，
顶端路径会往左滚，把 `Season 1`（当前这一层）露在最右边，左边只留能放下的那几层。
中间某一层被挤出去了没关系 —— 想看完整名字，顶栏标题上一直有。

不需要任何操作，也没有开关：这就是「该显示哪一段」的正确答案。

## 三、几点说明

- **只影响「浏览」页**的列表和它顶端的路径条。「媒体库」「最近」「收藏」「播放列表」
  这几页本来就不会在返回时丢掉位置（它们的列表一直活着，没有离开过界面），
  本次没有改动。
- **记住的位置活在内存里，不写盘**：退出应用再进来是全新的一次，从顶上开始。
  这是刻意的 —— 「上次翻到哪儿」属于这一次浏览的上下文，不属于长期记忆；
  把它写进磁盘反而会出现「关了应用三天，回来还停在一个已经变样了的目录中间」。
- **最多记住 20 个目录**（最近用过的 20 个）。更早的目录回去时回到顶上，
  和「根本没记过」表现一致，不会出错。
- **目录内容变短了也不会停在空白处**：上次停在第 40 行，这次这个目录只剩 12 项
  （文件被删了、换了排序、关掉隐藏开关），恢复时会自动夹到最后一条。
- 没有新增权限、没有新增后台行为，也没有改动文件格式或数据库。

## 四、为什么这一项修起来不是「加一个 remember」

症状看着像「滚动位置丢了，记一下就好」，实际上 `remember` 记不住 —— 而且原因是设计上的必然：

「浏览」页的目录内容是**流**里的一帧。每次切目录，流都会先发一帧「正在读」，
再发真正的内容。界面照这一帧把列表整个换成了转圈，那一列连同它的
`rememberLazyListState()` 一起被销毁；等真正的内容到了，是一列**全新的**列表。
`remember` 存的东西活在列表自己身上，列表一没了它就没了 —— 所以从子目录返回父目录，
必然回到顶端。

于是位置只能记到**组合外面**（由 ViewModel 持有），回来时再作为**初始值**交给新列表。
连带的两个小结论：

- 恢复之前必须按「现在还剩几条」夹一下，否则会落在空白上；
- 保存不能在「离开界面的那一刻」做 —— 那一刻的执行顺序在换内容时会读到旧值
  （文档里写清了原因），所以改成**每滚动一下就记一次**。这份记录没有被状态容器
  包着，写它不会触发任何重组，每帧一次整数写入的代价可以忽略。

## 五、已知限制

- 最多记住 20 个目录，更早的回到顶部。
- 不跨进程：杀掉应用（或者让系统回收掉）再打开，从顶上开始。
- 记的是**位置**而不是**文件**：如果那个目录在离开期间被大改（新增、删除、改名了一批文件），
  恢复的位置会按新列表夹住，可能不再对着同一个文件。按文件记的方案被否掉了 ——
  文件已经不在时它无从恢复，反而会出现「进目录直接空白」。
- 只在列表视图生效（「浏览」页没有网格视图）。
- 「浏览」页最外层的来源清单（内部存储 / 存储卡 / 网络地址）本来就只有三四行、不需要滚动，
  这次也没有特殊处理。
- 面包屑停在**最后一段的开头**：如果当前这一层的名字本身比屏幕还宽，露出来的是它的前半截
  （完整名字在顶栏标题上）。面包屑要交代的是「在哪一级」，不是「叫什么」。

## 六、升级注意

- 版本号 `1.4.8` → `1.4.9`，versionCode **10408 → 10409**，可直接覆盖安装。
- 升级后行为立即生效，**不需要任何开关**，也不需要重新选目录。
- 逆操作：没有开关 —— 这一版修的是一个「本来就该这样」的行为，不是一个可选偏好。
  如果你更希望每次返回都从顶上开始，这个需求请单独提，可以再做成设置项。
