# v1.4.11 「浏览」页终于记得自己走到哪了

发布日期：2026-10-30

基于版本：v1.4.10

---

## 一、这一版带来了什么

v1.4.10 的说明里留了一条「已知问题」：切换底部标签会把当前标签的页面状态整个重置。
这一版只修「浏览」，并且顺手补上一件一直缺的事 —— **点当前标签能回到该标签首页**。

| | v1.4.10 的样子 | v1.4.11 的样子 |
| --- | --- | --- |
| 在「浏览」里进目录、滚到中途，切到别的标签再切回来 | 回到来源清单，再进目录从第 1 项开始 | **还停在那一层、那一行** |
| 离开「浏览」很久（超过 5 秒）再切回来 | 同样重置 | 同样停在那一步 |
| 在「浏览」深处再点一次「浏览」 | 什么都不会发生（标签高亮着，但没有回家的路） | **回到来源清单** |
| 在「网络地址」页点「浏览」 | 无反应 | 弹回浏览页（来源清单） |
| 在「收藏」页点「媒体库」 | 无反应 | 弹回媒体库首页 |
| 在播放页点「媒体库」 | 退出播放页，回到媒体库 | **不变**（这是必须守住的旧行为） |

一句话：**「浏览」里的目录深度和滚动位置不再因为切标签而丢失；点当前标签就是「回到这一栏的首页」。**

## 二、怎么用

不需要任何设置，升上来就是这样：

- 在「浏览」里进到深一点的目录，切到「媒体库」看会儿视频，再点回「浏览」——
  你还在刚才那一层、停在那几行附近。
- 想回到「浏览」最外面那层（来源清单），**再点一次底部已经亮着的「浏览」**。
  「网络地址」页点「浏览」、「收藏」页点「媒体库」是同样的用法。
- 从播放页点底部任意标签，仍然是「离开播放、回到那一栏」——和以前一样。

## 三、几点说明

- 记住的是**「走到哪一层、滚到第几行」这个位置**，不是「记住某个文件」。它只活在内存里：
  退出应用再进来是全新的一次。
- 「浏览」最多记住 20 个目录的滚动位置（和 v1.4.10 一样）。
- 只改了底部标签的切换行为和「浏览」页的状态归属：**没有新增权限、没有新增后台行为**，
  没有改动文件格式或数据库，也没有改动任何界面文案。

## 四、变更清单

- 修复：切换底部标签不再丢失「浏览」页的目录深度与滚动位置。
- 新增：点当前标签回到该标签首页（含「网络地址」→「浏览」、「收藏」→「媒体库」）。

## 五、已知限制

- **「最近」「播放列表」切换标签后仍会回到列表顶部。** 它们的滚动位置存在页面里，
  页面被切标签清掉后就没了。这一版按约定只修了「浏览」，这两页留待后续版本。
- 之前列出的其他限制（最多记住 20 个目录、不跨进程、记位置而不是记文件）保持不变。

## 六、升级注意

- 版本号 `1.4.10` → `1.4.11`，versionCode **10410 → 10411**，可直接覆盖安装。
- 行为立即生效，不需要开关，也不需要重新选目录。
