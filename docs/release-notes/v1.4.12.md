# v1.4.12 「媒体库」终于可以只听你的

发布日期：2026-10-31

基于版本：v1.4.11

---

## 一、这一版带来了什么

以前「媒体库」会把设备上所有能扫到的音乐和视频都列出来——手机里存着几百个录音、
几百个截图、几百个别人发来的短视频，媒体库就得跟着一起乱。你没法告诉它「我只看这两个文件夹」。

这一版加了 **媒体库文件夹偏好**：你勾哪几个文件夹，媒体库就只显示那几个文件夹里的内容。

| | v1.4.11 的样子 | v1.4.12 的样子 |
| --- | --- | --- |
| 媒体库的内容 | 设备上能扫到的全部音乐、视频 | **只显示你勾选的文件夹里的** |
| 想只看一个音乐文件夹 | 没办法，只能在一堆条目里翻 | 设置里勾一下，媒体库就只剩它 |
| 一个文件夹都不勾 | —— | 媒体库是空的，并告诉你「还没有选择任何文件夹」 |
| 改完偏好之后 | —— | 立刻生效，**不重新扫描**，等下不用等 |
| 文件夹多起来以后 | —— | 带子文件夹的行尾有箭头，**可以折起来**，先只看顶层 |
| 「浏览」页 | 全部文件 | **完全不变**（还是全部文件） |

一句话：**「媒体库」从此是个你可以自己划范围的页面，而「浏览」仍然是完整的文件管理器。**

## 二、怎么用

1. 「设置」→「媒体库文件夹」。
2. 页面上是一棵文件夹树，括号里的数字是这个文件夹里有多少项（含子文件夹）。
   勾上你要的，取消你不要的。
3. 一进来只展开最外面那一层。某个文件夹行尾有箭头就说明它底下还有子文件夹，
   点箭头把它折起来或展开。**折叠只是为了看着清爽**：折起来的文件夹里的内容该进库照样进库，
   不会因为折起来就被当成「不要」。
4. 回到「媒体库」，就只剩这些文件夹里的内容了。改完立刻生效，不需要等。
5. 想清空重来，点右上角的「全不选」。

已勾选的文件夹那条链会自动展开，所以不用担心「我明明勾了却看不见自己勾的是哪一条」。
折叠状态不会保存：下次进入这一页，又是只展开顶层、勾选全部照旧。

第一次装上、或者从旧版本升级上来时，**一个文件夹都没勾，所以媒体库是空的**，
页面上会有提示和一个「去选择文件夹」的按钮，点它直接跳到上面那一页。
这是有意为之：不去猜你想看哪个文件夹，而是问你一次。

## 三、几点说明

- **勾一个文件夹，等于勾它里面的所有子文件夹。** 勾上 `Movies`，`Movies` 底下那些子目录
  里的东西也会一起显示，不用一个个勾。
- **子目录行会跟着显示成勾选状态。** 勾了 `Movies` 之后，它下面的子目录也会显示成勾上——
  因为对这些子目录来说，「它的内容会不会显示」的答案同样是「会」。
- **折叠不会改变你的选择。** 折起来的文件夹仍然是勾着的，里面的内容照样进媒体库；
  折叠只是让这一页少画几行。反过来，折叠也不会替你多跑一次扫描。
- **只影响「媒体库」这一页。** 「浏览」里的文件和目录一个都不会少，播放、字幕、歌词、
  「最近」「播放列表」的行为也和以前一样。
- **不会动你的文件。** 偏好只是「显示哪些」，取消勾选不会删除、移动、重命名任何东西。
- **改偏好不会重新扫描。** 只是换了个过滤条件，所以再怎么点都不会有「正在扫描」的等待。
- **没有新增权限、没有新增后台行为**，没有改动文件格式或数据库。

## 四、变更清单

- 新增：「设置 → 媒体库文件夹」，勾选的文件夹决定媒体库显示哪些内容（勾父级含子文件夹）。
- 新增：文件夹树可折叠/展开（首屏只看顶层，已勾选的链自动展开；折叠不影响勾选与过滤）。
- 新增：媒体库空态提示「还没有选择任何文件夹」+「去选择文件夹」一键直达。
- 新增：偏好子页的「全不选」，以及设置页那一行的摘要（已选 N 个 / 一个都没勾 / 无法读取）。
- 改进：修改偏好后立即重新过滤，不触发重新扫描。

## 五、已知限制

- **Android 9 及更早的系统上，文件夹偏好不起作用。** 这些版本的系统不告诉应用「文件在哪个
  子目录」，应用没法判断某个文件属不属于你勾的文件夹。为了不让媒体库在这种情况下变成空的，
  这一类设备上会**直接关掉过滤、照常显示全部内容**；「设置 → 媒体库文件夹」那一页会写明
  「系统不支持」并说明原因。也就是说勾选在这些设备上不会改变显示结果——不是坏了，是做不了。
- **通过第三方网盘/云存储类来源添加的文件**（不是手机本地存储）也拿不到子目录信息，
  启用过滤时它们会被排除。
- 偏好只存在本机，不跨设备同步；卸载重装会回到「一个都不勾」。
- 老限制没有变化：媒体库仍然是在启动时扫描出来的结果，新拷进来的文件需要刷新才会出现。

## 六、升级注意

- 版本号 `1.4.11` → `1.4.12`，versionCode **10411 → 10412**，可直接覆盖安装。
- **Android 10 及以上的设备，升级后「媒体库」会是空的**（因为还没有勾任何文件夹），
  这是本版的预期行为：去「设置 → 媒体库文件夹」勾一个就能看到内容。文件一个都没丢。
- **Android 9 及更早的设备升级后媒体库不变**（照常显示全部内容），详见上面「已知限制」。
- 其它页面的行为不受影响，不需要重新设置任何东西。
