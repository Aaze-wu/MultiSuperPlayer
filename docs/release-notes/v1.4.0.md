# v1.4.0 数量与提示

发布日期：2026-10-19
基于版本：v1.3.0

---

## 一、这一版带来了什么

这一版处理的是「翻目录」和「屏幕上那几句话」两件事，都很小，但每天都会碰到：

| 新功能 | 怎么用 | 解决什么 |
| --- | --- | --- |
| **文件夹里有多少项** | 进「浏览」页任意目录：顶部面包屑右边写着「共 N 项」，每个子文件夹的名称右侧写着「N 项」 | 一堆同名同类的文件夹排在一起时，不用一个个点进去才知道哪个是空的、哪个有东西 |
| **说明类提示可以关掉** | 提示右侧多了一个 ×；关掉后永久不再出现。想找回：设置 → 最底下「恢复所有提示」 | 看过一遍的「怎么用」每次进页面都占一行，看久了只是噪音 |

可以关的提示一共三处，都是「教你怎么用」的说法：

- 浏览页顶部那句「这里列的是可以开始浏览的位置。」
- 播放列表页那句「长按条目可拖动排序。」
- 播放队列面板底部那句「按住右侧把手上下拖动可调整顺序。」

**警告类提示没有 ×** ——它们说的是「现在有一件事不对」，关掉之后你就再也没有线索了：
缺「所有文件访问」权限、目录条目被上限截断、播放列表里有找不到的文件、随机播放时不能手动排序。
这一条是这一版最重要的边界，下面第四节单独讲。

既有能力全部不变：媒体库、浏览、最近、播放列表、收藏、字幕与歌词、桌面歌词、翻译、
网络播放、外部打开与分享、语音识别与清空识别缓存、播放时禁止熄屏、检查更新与自动检查间隔、
后台保活、权限页。本版**没有**新增任何系统权限，也没有新的系统行为。

## 二、怎么用

### 文件夹里有多少项

1. 底部切到「浏览」，点「内部存储」「存储卡」，或者你自己添加过的那个文件夹。
2. 每一行的名称右边会有一个淡色的小数字：「`3 项`」「`21 项`」。文件行没有这个数字，
   只有文件夹有——文件里没有「项」。
3. 面包屑那一行的右边是这一层自己的总数：「`共 486 项`」。
4. **统计口径**：只算这一层的**直接子项**，文件与文件夹**各算 1**，**不递归**。
   `Download` 里有 2 个文件夹、6 个文件，就是「共 8 项」，不会把子文件夹里的东西重复计入。

### 关掉一个提示

1. 看到提示，按它右侧的 ×。
2. 提示立刻消失，**以后不再出现**（退出应用、重启手机都不会再出现）。
3. 想让它回来：设置 → 往下滚到底 →「恢复所有提示」→ 按「恢复」。
   这一行的副标题会告诉你现在关掉了几条；一条都没关时它写「还没有关闭任何提示」，右边的按钮不出现。

「恢复」只恢复提示，不动你的任何其他设置、播放记录、播放列表、收藏。

## 三、几点说明

- **数量不是实时更新的。** 它是「列这个目录的那一刻」磁盘上有几项。在别的应用里往这个文件夹
  加了一个文件，这里不会自己变；退出再进一次目录（或重新扫描）才会更新。要做到实时就得一直
  盯着整个磁盘，那比这个数字本身贵得多。
- **「共 N 项」包含隐藏项。** 它是这个目录的真实数量，不是当前视图里画了几行。所以
  关着「显示隐藏文件」时它也可能比列表里的行数大——打开那个开关数字不变，行数才变。
- **空目录不显示总数。** 一行都不显示比「共 0 项」更安静，而空目录本来就有一句「这里什么都没有」。
- **添加进来的文件夹（SAF 目录）会慢一点。** 内部存储/存储卡的数量是查本地目录，
  系统目录（你自己选的文件夹）的数量要额外向系统查一次，所以**列表先画出来，数字随后补上**。
  刚进目录时那一列可能短暂是空的，属于正常。
- **极少数目录会一直没有数字。** 系统拒绝查询（授权被别人撤销、目录已经不存在）时，
  那一行**空着**而不是显示「0 项」——「问不到」和「里面是空的」是两件不同的事，
  给一个 0 会让你以为文件夹被清空了。
- **播放队列面板里，开着「随机播放」时底部那句话是另一句，而且没有 ×。**
  它写的是「随机播放开启时不能手动排序：列表顺序已不是播放顺序」——这解释的是
  「为什么现在拖不动」，不是一个用法提示，关掉之后你只会看到一个拖不动的列表。
- **关掉的提示存在本机。** 它是一份本地偏好，不跟着「导出播放记录」走（那一份只含播放记录和播放列表）。

## 四、为什么只有说明类提示能关

界面上那些一句话的横条，按「关掉之后会发生什么」分成两类，这一版只允许关其中一类：

- **说明类**：「这个功能可以这么用」。看过一遍就够了，关掉不会有任何信息丢失。
  上面三处都属于这一类。
- **警告类**：「现在有一件事不对，你可以做点什么」。它是**唯一的线索**：权限没开、
  条目被截断、播放列表里的文件找不到。关掉之后症状会变成「莫名其妙不能用」，
  而屏幕上再没有任何东西指向原因。

所以「能不能关」不是界面上逐个决定的，而是**一张固定的白名单**（代码里的 `HintIds`）：
只有写进白名单的那几个 id 才允许被关掉，写不进去的 id（包括拼错的）会被直接忽略、
不落盘。这样以后新增一条警告时，它天生就是不可关的——不需要谁记得去关掉那个 ×。

代价是这一版没有「提示管理页」：你只能在设置里一次性恢复全部，不能挑一条恢复。
三条提示的数量下，多一层列表反而是负担。

## 五、已知限制

- **数量不做递归统计**：不显示「这个文件夹连同里面一共有多少项」，只有这一层的。
- **数量不区分文件与文件夹**：没有「12 个文件 / 3 个文件夹」这种拆开显示。
- **数量不实时**：见上一节第一条。
- **网络地址与单独的文件不会显示数量**：它们不是目录。
- **只能关掉那三条说明，且只能一次性全部恢复**：没有逐条恢复，也没有提示管理页。
- **关掉一条提示是不可撤销的**（除了在设置里恢复全部）——这正是「关掉」的意思，
  所以界面上不做二次确认；恢复入口就在设置最后一行的位置，找得到。
- 本版没有改动字幕匹配规则、翻译、语音识别、桌面歌词、更新通道的任何行为。

## 六、升级注意

- `versionCode` **10400 > 10300**，可以直接覆盖安装 v1.3.0 及更早版本，不会提示降级。
- **升级之后不需要做任何事**：所有提示都在（你之前从没关过），数量显示直接生效；
  已有设置、播放记录、播放列表、收藏、字幕与译文都会沿用。
- 提示的关闭状态是这一版才有的新数据。从 v1.4.0 退回旧版本时它只是被忽略，
  旧版本照旧显示全部提示，不会因此出错。
- 关于页不显示「测试版」徽章（正式版不显示徽章）。
