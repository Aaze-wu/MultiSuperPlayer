# v1.4.13 「媒体库」打开得更快了

发布日期：2026-11-04

基于版本：v1.4.12

> 这是**正式版**。`1.4.13-beta.1` 的内容原样收进这一版，另外补上测试期间发现的两处修正。
> 已经装了 `1.4.13-beta.1` 的可以直接覆盖升级，数据不受影响。

---

## 一、这一版带来了什么

这一版主要做一件事：**让「媒体库」更快出现内容。**

以前打开媒体库，要等应用把你在「浏览」页里授权过的那些目录**整棵树**走完，才会显示任何东西。
目录里文件一多，这段等待就变成转圈。这一版做了两处改动：

| | 之前 | 现在 |
| --- | --- | --- |
| 什么时候才显示列表 | 等授权目录全部扫完 | **先把手机媒体库里的内容列出来**，授权目录扫完再补进来 |
| 扫一个授权目录要问系统多少次 | 每个文件大约 **5 次**（名字、类型、是不是目录、大小、修改时间各问一次） | 每个**目录** **1 次**，一次把这一层的信息全拿回来 |
| 文件很多的目录 | 等待时间和文件数成正比，越堆越久 | 等待时间主要跟**目录层数**有关，跟文件数基本脱钩 |

一句话：**同样是几百首歌，以前要替两万份文件挨个问系统，现在只问文件所在的那些目录。**

主线之外，本版还修了一处会影响日常使用的问题：

**「设置 → 媒体库 → 媒体库文件夹」里的「存储根目录」那一行以前是坏的**——它显示「0 个文件」，
勾上它也不等于把整个存储算进来，那些直接放在存储根下的文件因此怎么勾都进不了媒体库。
现在它显示的是**这一整卷的文件数**，勾上它就是**全选**。

## 二、怎么用

装好以后，像平常一样打开「媒体库」，留意从点开到底部出现列表的等待时间。

这一版的提速**只在授权过目录时才明显**——也就是那些你用系统文件选择器加进来的目录。
如果你授权过，请重点拿这些目录做对比；纯粹用手机媒体库里的内容，本来就快，
看不出差别是正常的。

想拿数字的话：「设置 → 关于 → 导出日志」，日志里有一条「扫描耗时」，
写着手机媒体库那半边和授权目录那半边各自用了多少毫秒、各有多少条。

想改媒体库的范围：「设置 → 媒体库 → 媒体库文件夹」，勾选你想让媒体库包含的文件夹。
勾「存储根目录」= 整卷都要；只勾几个子文件夹 = 只看这几处。「浏览」页完全不受这个设置影响。

## 三、几点说明

- **能看到的内容不会变少。** 扫描方式换了，但扫出来的结果还是同样的那些文件。
- **没有新增权限，没有新增后台行为**，也没有改动任何设置项和数据格式。
- 这一版与 `1.4.13-beta.1` 的扫描代码**完全一致**，测试期间没有出现需要撤回的问题，
  所以直接转为正式版，而不是再开一轮测试版。

## 四、（顺带修正的）

- 修好了「撤掉最后一个授权目录之后，媒体库里还留着那个目录里的条目」。
  以前这些条目会一直在，点开还会报错；现在撤掉就会一起消失。
- 修好了「媒体库文件夹」里「存储根目录」那一行：以前显示 0 个文件，勾上也不等于全选。
  现在它显示整卷的文件数，勾上就是全选。
  反过来，**把根节点取消勾选**等于「除了我取消的那些，其余全要」，所以那一项会被展开成兄弟节点——
  代价是**直接躺在存储根下的那几个文件从此不在库里**（「一份路径清单」表达不了
  「除了 X 以外全都算，而且存储根下的也算」），要它们就把根重新勾上。
- 顺手补齐了 `README.md` / `README.en.md` 里过时的说明（不是应用内行为）：
  播放页手势写成了「双击两侧 ±10 秒」（实际双击是播放 / 暂停），
  当前版本号与版本表还停在 1.4.8，1.4.9 之后的几版改动完全没有记录。

## 五、已知限制

- **还没有做「记住上次的扫描结果」。** 每次冷启动仍然要把两个来源扫一遍，只是这一次
  每一步都便宜很多。要让下一次启动直接出列表，还要再做一次改造，留到后续版本。
- **授权目录特别大的时候，第一次扫描仍然要时间**（少了，但没有归零）。
  这版把成本从「按文件数」压成了「按目录数」，没有改变「要遍历一遍」这件事。
- 改善幅度**跟设备、存储类型、目录结构有关**，不会是同一个数字。
- 「媒体库文件夹」存的是一份**路径清单**，表达不了「除了某个子文件夹以外全都要，
  而且存储根下的文件也算」。要这种效果请在子文件夹层面勾选。
- 切换底部标签仍然会把「最近」「播放列表」的滚动位置重置；这是旧版本就有的行为，留到后续版本。

## 六、升级注意

- 版本号 `1.4.12` → `1.4.13`，versionCode **10412 → 10413**，可直接覆盖安装。
- `1.4.13` 与 `1.4.13-beta.1` 的 versionCode 相同（同一数值段共用），但正式版在更新比较里
  比同段的测试版更新，所以**留在测试版通道的用户也会收到这一版**。
- 不需要重新设置任何东西：之前勾过的文件夹偏好、播放列表、最近播放、字幕设置都照旧。
