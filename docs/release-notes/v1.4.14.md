# v1.4.14 随机播放不再「第二轮原地复读」

发布日期：待定（本地构建与模拟器验证已完成，尚未提交 / 打 tag）

基于版本：v1.4.13

> 这一版只改两件事：**随机播放怎么走**，以及**「关于」里那份更新说明怎么写、多长**。
> 没有新权限，没有新设置项，数据不受影响。

---

## 一、这一版带来了什么

### 随机播放：一轮播完，换一条新路线

以前随机播放有一个不太像「随机」的毛病：**第一轮怎么走，第二轮还是怎么走。**
整个队列随机洗一次，然后这张表就一直用下去，播到末尾绕回开头——绕回去用的还是同一张表，
所以第二遍听起来就是第一遍的原样重播。

这一版改成：**每次切歌，把「还没播的那一部分」重新洗一遍。**

| | 之前 | 现在 |
| --- | --- | --- |
| 一轮播完之后 | 第二轮和第一轮顺序完全一样 | **第二轮是一条新路线** |
| 中途打开随机 | 可能被扔回第 1 首 | **从你正在听的这一首起步** |
| 已经听过的那一段 | 跟着新表一起变 | **永远不重排** |
| 关掉随机 | — | 只取消随机标记，**不改你的队列顺序** |

「已经听过的那一段永远不重排」这条是硬要求，不是取舍：如果不冻结，
「上一首」就会落到一首你**根本没听过**的歌上。

### 「关于」里那份更新说明：只讲这一版

以前那一页从 1.2.0 起只增不减，每版往里追加，越读越长。你想知道的其实是
「我刚装上的这版改了什么」，不是两年份的变更史。

现在它只有一句总述 + **5 条要点** + 一句已知问题 + 一句已知限制。旧版本的变化在
各版发行说明里，页内有一句话指路。

顺带把那一页的对话框修好了：正文变长时，以前它会把「关闭」按钮顶出屏幕，
只能按返回键。现在正文高度按屏幕比例收（小屏收得更多），超出就能滚，
底部还有一层淡出——看得见「下面还有字」，最后一行也不会被硬切掉半个字。

## 二、怎么用

**随机播放**：播放页打开随机，照常听。想验证这一版的改动，最直接的办法是
**把一轮听到底**，让它在末尾绕回开头——第二轮的顺序应该和第一轮不同。
也可以在听到第 7、8 首时打开随机，播放位置不该跳。

**更新说明**：设置 → 关于 → 本版更新说明。

## 三、几点说明

- **「下一首」在随机播放时没有固定答案**，界面也就不预告它。因为「还没播的部分」
  每次切歌都重洗，下一首本来就不该是固定的——这是随机播放的应有之义，
  不是卡顿，也不是跳歌。
- **关掉随机只是取消标记**，不会把你被打乱的队列变成「新的队列」。关掉之后看到的顺序，
  就是你当初排的顺序。
- **队列页显示的是你自己的队列顺序，不是打乱后的顺序**（这一点本版没有改）。
- 随机播放时手动排序仍然是禁用的（同样没有改）——要调整顺序先关掉随机。

## 四、（顺带修正的）

- 「本版更新说明」的对话框：正文高度改成按屏幕高度的比例，而不是一个固定值。
  以前用固定值时，正文略长就会在屏幕还有余量的情况下把最后一行切掉。
- 那个对话框底部加了一层淡出遮罩，纯观感修正：能滚的时候看得到「下面还有字」，
  滚到底自动消失。

## 五、已知限制

- **随机顺序只在本次运行内有效。** 退出应用后重新开始一轮，不记得上次的随机结果
  （这个开关本身也不保存）。
- **队列页显示的是你自己的队列顺序**，不是打乱后的顺序。所以「下一首是哪个」
  在随机播放时确实看不到，这是上一条的直接结果。
- **随机播放时不能手动排序。**
- **随机播放的实际听感已经真机验过**：6 首测试音频连听 4 轮，每轮 `6` 首都播满、
  每轮路线都不同、跨轮边界不会紧接着重播刚听完的那一首；「上一首」逐首精确回溯。
- **跨轮边界可能与最近 2 首中的一首重叠。** 这是刻意的权衡：完全不重叠会让新一轮
  开头几首变得可预测，音源少时随机感反而更弱。
- **切换底部标签仍然会把当前标签的页面状态整个重置**（从别的标签回到「浏览」会落在
  第一屏）。这是旧版本就有的行为，本版没有动，留到后续版本。

## 六、升级注意

- 版本号 `1.4.13` → `1.4.14`，versionCode **10413 → 10414**，可直接覆盖安装。
- **没有数据格式变化**：播放列表、最近播放、字幕与翻译设置、媒体库文件夹偏好都照旧。
- 升级后第一次打开「本版更新说明」会发现内容**明显变短**，这是本版的设计，不是文案丢失。
