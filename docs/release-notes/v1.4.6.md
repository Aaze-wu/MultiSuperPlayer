# v1.4.6 办公文档与电子书不再被当成音频

发布日期：2026-10-28
基于版本：v1.4.5

---

## 一、这一版带来了什么

这一版只修一处，但它属于「看着莫名其妙、其实必然发生」那一类：**Word / Excel / PowerPoint
这类办公文档，以前点一下会被当成一首歌打开。** 电子书、WPS 文档、PDF 之外的各种版式文档、
帮助文件也都一样。

| 修了什么 | 以前的样子 | 现在的样子 |
| --- | --- | --- |
| **办公文档被当成音频** | 在「浏览」里点 `报告.docx`，直接进了播放页：标题是文件名、下面是一条空进度条，界面是一套**音频**版面，几秒后报「无法播放」 | 这一行照常列出来，但**点不动**（右侧写着它自己的后缀 `DOCX`，图标是中性文档图标），不会被当成歌曲 |
| **电子书、WPS、OFD、iWork 等** | 同上：`小说.epub`、`公文.ofd`、`演示.wps`、`页面.pages` 都能「播放」 | 同上：列出来、看得见、点不动 |
| **多选与队列** | 这些文件参与多选、能被加进播放列表，点「下一首」会停在一个必然失败的条目上 | 不进队列、复选框是禁用的、也不会出现在「最近」里 |
| **从别的应用分享进来** | 分享一叠文件时，里面的 `.docx`、`.txt`、`.jpg` 会被当成可播条目塞进队列 | 分享时直接剔掉，只收能播的 |

既有能力全部不变：媒体库、浏览、最近、播放列表、收藏、字幕与歌词、桌面歌词、翻译、
网络播放、外部打开与分享、语音识别与清空识别缓存、播放时禁止熄屏、检查更新与自动检查间隔、
后台保活、权限页。本版**没有**新增任何系统权限，也没有新的系统行为。

---

## 二、怎么用

这个修复**不需要你做任何事**：升级之后，那些文件的显示方式自己就变了。想确认一下的话：

1. 准备一个 `.docx`（或 `.xlsx`、`.pptx`、`.epub`、`.wps`、`.ofd`）。
2. 把它放进手机里任一目录（下载、文档、Movies 都行），或者在电脑上 `adb push` 进去。
3. 打开 App → 底部切到「浏览」→ 进入那个目录。
4. 你会看到它：**右侧写着 `DOCX` / `EPUB` / `WPS` 这样的后缀**，图标是文档样式的图标。
5. **点它没有任何反应**——这就是对的样子（以前会直接跳进播放页）。
6. 长按也没用：复选框是灰的，选不上。
7. 对照一下：同一目录里的 `test.mp4` 照常点开、照常播放、照常进「最近」。

## 三、几点说明

- **「看得见」和「能播」是两件事。** 以前「浏览」页把「后缀不认识」当成「也许是媒体，
  交给解码器试试」，所以任何文件都可点——这对没有后缀的视频（`VID_20240101` 这种）是必须的。
  这一版没有推翻这条思路，只是把**已经确定不是媒体**的那一批后缀明确写了出来。
- **判断顺序变了：后缀优先于 MIME。** 从系统拿到 `.docx` 的类型时，有些机器会报
  `audio/mpeg`（很常见的错报）。以前照着 MIME 走就把它当成音频；现在「后缀明确不是媒体」
  这一步在 MIME 之前，报什么都不影响结论。
- **没有把 `psd` / `ai` / `sketch` / `fig` 加进去。** 这张后缀表还被「这串字是不是一个网址」
  的判断借去用（`xxx.com` 这样的主机名要能放行），而 `.ai` 是真实的国家顶级域名，
  写进去会让 `xxx.ai` 这种网址被当成「不是网络地址」。同理 WPS 的表格后缀 `.et`
  也没有加：`.et` 是埃塞俄比亚的国家顶级域名。
- **本版没有改动**字幕匹配规则、翻译、语音识别、更新通道、桌面歌词、状态栏图标的任何行为。

## 四、为什么 docx 会打开成音频

「这个文件能不能播」在代码里其实是三个问题叠在一起：**后缀认不认识**、**媒体库怎么标**、
**内核放不放得了**。第三件事（真的解码一次）代价最大，所以放在最后，前两件先用便宜的办法过一遍。

第一件以前是这么办的：「如果后缀在音频表里 → 音频；在视频表里 → 视频；都不在 → 类型不明」。
最后一档是**故意留的**：没有后缀的视频、老式数码相机起的怪名字，都靠它才播得出来。
代价是「类型不明」必须被当成「可能能播」，否则这些文件就永远打不开了。

于是问题出在第二件事没人接：`.docx` 不在音频表、不在视频表，落到「类型不明」，
而系统给的 MIME 恰好又常常是错的（`audio/mpeg`），两步都没有拦下它 ⇒ 判定为「可播」。
播放页的版面只有**音频**和**视频**两套，判据是「是不是视频」，不是视频就画音频版面——
所以你看到的是一首歌的样子：标题、一条进度条、一条走不动的时间轴。真正的解码失败要等
内核真的试过一次才发生，日志里也不一定留下什么，于是在用户眼里就是「它以为这是个音乐」。

修法不是让「类型不明」变成不可播（那样会误伤真正的无后缀视频），而是**把那张「明确不是媒体」
的后缀表补全**：办公文档、电子书、压缩包、安装包、字体、图片、字幕这些本来就放不了的东西，
在第一步就被划出去。`UNKNOWN` 的含义由此收窄成「我们不知道，让内核试试」——它仍然可点，
仍然可能失败，但它不再是「所有奇怪文件的垃圾桶」。

## 五、已知限制

- **后缀表按常见格式列**：非常冷门的办公格式（比如某些国产排版软件的专有后缀）仍可能被当成音频。
  遇到时把后缀反馈过来，加一行就好。
- **没有后缀的文件仍然可点。** 这是刻意保留的：`VID_20240101`、`REC001` 这类文件靠的就是这条路。
  如果它其实不是一个媒体文件，播放页会报「无法播放」——这是内核给出的诚实结论。
- **改了后缀名就能绕过**：把 `.docx` 改名成 `.mp3`，它仍然会被当成音频（然后解码失败）。
  判断只看名字与类型，不读文件头。
- **本版不改变字幕匹配、翻译、语音识别、更新通道的行为。**

## 六、升级注意

- `versionCode` **10406 > 10405**，可以直接覆盖安装 v1.4.5 及更早版本，不会提示降级。
- **升级之后不需要做任何事**：已有设置、播放记录、播放列表、收藏、字幕与译文都会沿用。
- 如果你的播放列表里**已经**有办公文档这类条目（v1.4.5 及以前加进去的），新规则**不会回头
  清理**它们——列表里存的是一条「当时加进来的什么」，这一版只改「现在还能不能加」。
  想清掉的话，在播放列表里长按删除即可。
- 想验证这处修复，见「怎么用」里的六步；最快的一步是「点一下 docx，没有反应」。
- 关于页不显示「测试版」徽章（正式版不显示徽章）。
