# v1.4.8 长文件名滚动显示

发布日期：2026-10-28

基于版本：v1.4.7

---

## 一、这一版带来了什么

| | 以前的样子 | 现在的样子 |
| --- | --- | --- |
| 列表里的长文件名 | 一行装不下就截断，后面全是 `…`，「片名 + 年份 + 版本 + 字幕组」这种名字永远只露前半截 | 那一行会先停一下，再慢慢往左走一段，把剩下的字走完再回来 |
| 哪一页会动 | —— | 默认**只有当前播放的那一条**会动；在设置的子页里可以把某一页（比如媒体库、浏览）**整页**点成「始终滚动」 |
| 不想要这个效果 | —— | 设置 → 外观 →「长文件名滚动」→ 关掉总开关即恢复成「装不下就省略号」；默认是**开着**的 |

一句话：**长文件名不再只剩开头几个字，而且你想让哪一页全部滚起来，就能让哪一页全部滚起来**。

## 二、怎么用

### 1. 默认行为：只滚「当前那一条」

1. 打开媒体库 / 浏览 / 最近 / 收藏 / 播放列表任意一个列表（或播放页上滑呼出的播放队列）。
2. 找一条名字长到一行放不下的条目。
3. 如果它就是当前正在播放的那一条 —— 等大约 0.9 秒，它会自己开始滚动，走到末尾停一下再走回来。什么都不用点。
4. 如果它不是当前那条：先播它（或在多选里勾上它），它就变成「当前那一条」，然后同样会滚。

### 2. 让某一页**全部**滚起来

文件选择器（浏览）和媒体库这种场景，用户常常是在**扫一串文件名**，而不是只关心正在播的那一条。所以：

入口：**设置 → 外观 →「长文件名滚动」**（在外观页的「列表显示」分组里，点这一行进子页）。

子页里有两个部分：

- 最上面是**总开关**（就是外观页那一行背后的同一个开关）。
- 下面「**始终滚动的页面**」有 7 行，一页一行：

  | 行 | 对应的是用户在哪儿看到的 |
  | --- | --- |
  | 媒体库 | 底部第一个标签页 |
  | 浏览 | 底部第二个标签页（文件选择器） |
  | 最近播放 | 底部「最近」 |
  | 收藏 | 媒体库右上角星标进去的那一页 |
  | 播放列表 | 底部「播放列表」，以及点进某个清单后的详情页 |
  | 播放队列 | 播放页上滑呼出的面板 |
  | 网络地址 | 浏览页顶部「网络地址」进去的那一页 |

- 勾上哪一页，**那一页里所有放不下的名字都会滚**，不再限于当前那一条。
- 一个都不勾（默认）就是回到「只有当前那一条会滚」。
- 名字短到一行放得下的行**永远不会动** —— 这一条由显示组件自己判断，不需要额外设置。

### 3. 三个层次的优先级

| 状态 | 结果 |
| --- | --- |
| 总开关关着 | 全部静止，恢复省略号截断。子页里逐页的勾选会**置灰但保留勾痕**，重新打开总开关后原样生效 |
| 总开关开着 + 某页没勾 | 那一页只有**当前播放或选中的那一条**会滚 |
| 总开关开着 + 某页勾了 | 那一页**所有放不下的**名字都会滚 |

子页里每一行的副标题会直接把当前状态写出来（「这一页里放不下的名字都会滚」／「只有当前播放或选中的那一条会滚」／「总开关已关闭，这一页也不会滚」），置灰的开关不会变成一句不说话的哑巴。

外观页上「长文件名滚动」这一行的副标题也会跟着变：「已关闭」／「只有当前播放或选中的那一条滚动」／「N 个页面始终滚动」。

## 三、几点说明

- **网格卡片不滚**。网格里的卡片本来就给标题留了两行，横向空间也够，改成滚动反而会削弱它「一眼扫一片」的用处。
- **播放页顶上那行大标题不滚**。那里的标题本来就是完整显示的（放不下就折行），没有「看不全」的问题。
- **来源清单不滚**（浏览页最外层那几行「内部存储 / 存储卡 / 网络地址」）。这些名字是应用自己写的固定文字，不会长到装不下；真正长的是用户自己的文件名，它们在进去之后的文件列表里，那一层是滚的。
- **短名字不动**。一行装得下就照常显示，不会为了「看起来一致」硬滚一遍。
- **系统开了「移除动画」时不滚**。Android 的这个开关对所有动画都生效，本版也照它来：关掉动画的用户得到的是「装不下就省略号」。
- 本版**没有**新增权限、没有新增后台行为、没有改动文件格式或数据库 —— 只是个显示上的改动。

## 四、为什么默认只滚「当前那一条」

这是本版唯一一个需要解释的设计决定。

如果所有装不下的行**默认**同时滚起来，一屏里可能有七八行在动，会同时坏掉两件事：

1. **看不出哪一条在播。** 播放中的那一行本来靠颜色和 ▶ 标记就能认出来，一旦周围全在动，视线会被拽走。
2. **一条也读不进。** 滚动是为了在有限宽度里读完一句话，而「读完一句」需要眼睛跟着一个目标走；目标一多，等于什么都没读。

所以默认规则是：**滚动只发生在「你此刻正在关心」的那一条上**。

但这个「只滚一条」的规则有一个它不成立的地方：**文件选择器和媒体库不是「关心一条」的场景，是「扫一片」的场景**。在这两页里，「只有当前那一条会滚」等于「几乎什么都不滚」，用户仍然只能看到前半截名字，然后被迫一个一个点开确认。所以本版才把「哪一页整页滚动」做成选项：默认保持克制，但需要扫列表的人可以按页打开。

## 五、已知限制

- 未勾「始终滚动」的页里，想读某一行完整的名字，得先让它成为当前那一条（播它，或勾上它）。不做「手指指到就滚」那种悬停式效果：手机上没有悬停。
- 网格视图与播放页标题保持原样，不滚（原因见上一节）。
- 名字本来就短、一行装得下的不会动。
- 系统开了「移除动画」时不滚。
- 「网络地址」那一页的行标题是从链接里取出来的文件名，通常不长；这一页之所以也列进去，是为了遇到真长的时候有得选。

## 六、升级注意

- `versionCode` 从 **10407** 升到 **10408**，直接覆盖安装即可，不需要卸载。
- 本版默认**开**着这个效果，但「始终滚动的页面」默认**一个都没勾** —— 升级之后的行为和「只滚当前那一条」完全一致，不会突然满屏滚动。想要整页滚的话按第二节第 2 步勾。
- 不喜欢这个效果：设置 → 外观 →「长文件名滚动」→ 关掉总开关。选择会被记住。
- 本版是正式版，关于页不会显示「测试版」徽章。
