# v1.4.8 长文件名滚动显示

发布日期：2026-10-28

基于版本：v1.4.7

---

## 一、这一版带来了什么

| | 以前的样子 | 现在的样子 |
| --- | --- | --- |
| 列表里的长文件名 | 一行装不下就截断，后面全是 `…`，「片名 + 年份 + 版本 + 字幕组」这种名字永远只露前半截 | 那一行会先停一下，再慢慢往左走一段，把剩下的字走完再回来 |
| 什么时候会动 | —— | 只有**当前播放的那一条**会动；多选里**被勾上的那一条**也会动，其余一律静止 |
| 不想要这个效果 | —— | 设置 → 外观 →「列表显示」 →「长文件名滚动」，关掉即恢复成「装不下就省略号」；默认是**开着**的 |

一句话：**长文件名不再只剩开头几个字**。

## 二、怎么用

1. 打开媒体库 / 浏览 / 最近 / 播放列表任意一个列表（或播放页右下角的播放队列）。
2. 找一条名字长到一行放不下的条目。
3. 如果它就是当前正在播放的那一条 —— 等大约 1 秒，它会自己开始滚动，走到末尾停一下再走回来。什么都不用点。
4. 如果它不是当前那条：先播它（或在多选里勾上它），它就变成「当前那一条」，然后同样会滚。
5. 不想让它动：设置 → 外观 →「列表显示」 → 把「长文件名滚动」关掉。所有列表立刻恢复成省略号截断。

## 三、几点说明

- **网格卡片不滚**。网格里的卡片本来就给标题留了两行，横向空间也够，改成滚动反而会削弱它「一眼扫一片」的用处。
- **播放页顶上那行大标题不滚**。那里的标题本来就是完整显示的（放不下就折行），没有「看不全」的问题。
- **短名字不动**。一行装得下就照常显示，不会为了「看起来一致」硬滚一遍。
- **系统开了「移除动画」时不滚**。Android 的这个开关对所有动画都生效，本版也照它来：关掉动画的用户得到的是「装不下就省略号」。
- 本版**没有**新增权限、没有新增后台行为、没有改动文件格式或数据库 —— 只是个显示上的改动。

## 四、为什么只滚「当前那一条」

这是本版唯一一个需要解释的设计决定。

如果所有装不下的行同时滚起来，一屏里可能有七八行在动，会同时坏掉两件事：

1. **看不出哪一条在播。** 播放中的那一行本来靠颜色和 ▶ 标记就能认出来，一旦周围全在动，视线会被拽走。
2. **一条也读不进。** 滚动是为了在有限宽度里读完一句话，而「读完一句」需要眼睛跟着一个目标走；目标一多，等于什么都没读。

所以本版选择的规则是：**滚动只发生在「你此刻正在关心」的那一条上** —— 正在播放的那一条，或者你刚刚勾上的那一条。这不是省事，而是「让滚动有意义」的前提。

## 五、已知限制

- 想读某一行完整的名字，得先让它成为当前那一条（播它，或勾上它）。不做「手指指到就滚」那种悬停式效果：手机上没有悬停。
- 网格视图与播放页标题保持原样，不滚（原因见上一节）。
- 名字本来就短、一行装得下的不会动。
- 系统开了「移除动画」时不滚。

## 六、升级注意

- `versionCode` 从 **10407** 升到 **10408**，直接覆盖安装即可，不需要卸载。
- 本版默认**开**着这个效果，所以升级之后立刻就能看到；不喜欢的话按第二节第 5 步关掉，选择会被记住。
- 本版是正式版，关于页不会显示「测试版」徽章。
