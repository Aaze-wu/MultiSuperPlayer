# v1.3.0 收藏与桌面歌词

发布日期：2026-10-19
基于版本：v1.2.4

---

## 一、这一版带来了什么

这一版加了两样「减少来回找」的东西：

| 新功能 | 怎么用 | 解决什么 |
| --- | --- | --- |
| **收藏** | 媒体库右上角星标 → 收藏页；多选时操作条上也有星标；浏览页顶栏的星标收藏「当前这个文件夹」 | 常听的那几个文件和那几个目录，不用每次从头翻 |
| **桌面歌词** | 设置 → 桌面歌词 → 打开开关，授予「显示在其他应用上层」 | 退出应用、在别的界面里做别的事时，歌词浮在上面跟着走 |

顺带补上了**最近播放页的多选**：以前只能在媒体库多选，最近播放这一页要一条一条处理；
现在长按任意一条就能像媒体库那样全选、加入播放列表、收藏。

既有能力全部不变：媒体库、浏览、最近、播放列表、字幕与歌词、翻译、网络播放、外部打开与分享、
语音识别与清空识别缓存、播放时禁止熄屏、检查更新与自动检查间隔、后台保活、权限页。
本版新增一条系统权限（桌面歌词用），其余没有新的系统行为。

## 二、怎么用

### 收藏

- **收藏一个文件**：在媒体库、浏览、最近播放里随便挑几条（长按进入多选），
  顶部的操作条上有一颗星，按一下就是收藏；已经是收藏的再按一下取消。
  星是实心的时候说明你选中的这些**全部**都已经收藏了。
- **收藏一个文件夹**：进到「浏览」页里那个目录，顶栏上（排序按钮左边）有一颗星，
  按一下收藏当前所在的目录。
- **打开收藏**：媒体库右上角那颗星 → 收藏页。文件和文件夹在一张清单里，最近收藏的排在最前。
- **点收藏里的文件夹**：会切到「浏览」页并**直接打开那个目录**，面包屑、排序、多选全都是
  熟悉的那个界面。
- **取消收藏**：在收藏页点那一行右侧的实心星即可。

### 桌面歌词

1. 设置 → 桌面歌词 → 打开「显示桌面歌词」。
2. 第一次打开会提示还缺「显示在其他应用上层」，按「去开启」跳到系统页面打开它。
   （这是系统的特殊授权，只为了能画一个浮动窗口，不会读你别的应用的内容。）
3. 播放一个**有字幕 / 歌词**的文件，然后按 HOME 退到桌面或切到别的应用，
   歌词浮窗会出现在屏幕下方居中。
4. 浮窗上有四个按钮：暂停 / 播放、字号变小、字号变大、锁定。
   - **锁定**之后浮窗点不动、触摸会穿透到下面的应用（防误触）。
     解锁要回到设置 → 桌面歌词，或者播放页控制条上那个「已锁定」按钮。
   - 直接**按住浮窗拖动**可以换位置；位置会记住。
5. 外观（字号 4 档、背景不透明度 4 档）也在设置 → 桌面歌词里，两处都有「恢复默认」。

播放页控制条上还有一个桌面歌词按钮，按下去会按当前状态做最该做的那一件事：
没授权就去授权、没开就开、锁着就解锁、都就绪了就关掉。

## 三、几点说明

- **桌面歌词只在「本应用不在前台」时出现。** 你在播放页里时，画面中本来就有字幕，
  再浮一个窗口出来只是在同一块屏幕上把同一句话写两遍。
- **桌面歌词用的就是当前文件挂载的字幕。** 没有字幕的文件不会有桌面歌词；
  它不会自己去生成。要生成的话，去播放页的字幕面板里用语音识别。
- **字幕显示模式是「关闭」时，桌面歌词也不出现。** 「关闭字幕」的意思是「不看文本」，
  这一条对画面里的字幕和桌面上的歌词是同一份设置。
- **锁屏时不显示桌面歌词。** 系统的悬浮窗本来就画不到锁屏上。
- **收藏是一个清单，不分文件夹也不分组**，最多 200 条。满了会明确告诉你「收藏已满」，
  不会悄悄丢掉你刚点的那一条。超过 200 条之后想整理的话，先取消一些旧的。
- **收藏的文件夹如果打不开了**（比如在系统设置里撤销了那个目录的授权、SD 卡拔了、
  目录改名了），点它会提示「这个文件夹已经打不开了」——而不是给你看一个空目录，
  让你以为文件被删了。
- **收藏的文件被删掉或移走之后**，收藏页里那一行仍然在，点开会说找不到文件。
  需要你自己点星标把它去掉；这一版不做自动清理。
- **收藏的名字是「收藏那一刻的语言」。** 在中文界面下收藏的文件夹，切到英文界面后
  仍然显示当时的中文名（和媒体标题一样，它们都是你的数据，不做实时翻译）。

## 四、为什么桌面歌词要一个新权限

在别的应用上面画东西，Android 只给一条路：`显示在其他应用上层`（系统设置 → 应用 →
特殊应用权限 → 显示在其他应用上层）。它不是普通的那种「点一下允许」的弹窗，
系统不给应用任何「已经授权了」的回调，所以这个开关的状态是本应用每次回到前台时重新读一次。

没有这条权限，桌面歌词是**开不了的**——不是效果差一点，而是一个窗口都画不出来。
所以本版的设置页在没授权时会把开关的状态写成「已开启，但还没有『显示在其他应用上层』权限，
现在不会出现」，而不是让开关自动弹回关闭：你的意图是「我要用」，缺的是系统那一步，
这两件事在界面上分开说，你才知道下一步该做什么。

## 五、已知限制

- **收藏没有搜索，也不能排序**：固定按收藏时间倒序，上限 200 条。
- **收藏不能分组或命名**：一个清单，文件夹里点进去看到的就是那个目录本身。
- **桌面歌词没有逐字高亮 / 卡拉 OK 效果**：它与播放页的字幕层用同一套渲染规则，
  画面里没有的效果，桌面上也没有。
- **桌面歌词不能在锁屏上显示**，也不能在画中画的小窗里替换画面内容（小窗里照旧是视频）。
- **桌面歌词只跟当前播放的那一个文件走**：切歌时内容会跟着换，但没有「同时显示两首」这种事。
- **桌面歌词的浮窗不会跟随系统深色/浅色**：它一直是「深底 + 白字 + 描边」，
  因为它是盖在别人应用上的，身后是什么颜色无法预料。
- 本版没有改动字幕匹配规则、翻译、语音识别、更新通道与自动检查间隔的任何行为。

## 六、升级注意

- `versionCode` **10300 > 10204**，可以直接覆盖安装 v1.2.4 及更早版本，不会提示降级。
- **升级之后不需要做任何事**：收藏清单从空开始，桌面歌词默认关闭；已有设置、播放记录、
  播放列表、字幕与译文都会沿用。
- 想要桌面歌词的话，第一次打开时会多一步系统授权（显示在其他应用上层）。不打开这一项，
  其余功能完全不受影响。
- 关于页不显示「测试版」徽章（正式版不显示徽章）。
